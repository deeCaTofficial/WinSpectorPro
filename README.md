## 🚀 Что нового в v1.0.4

Это обновление делает WinSpector Pro заметно проще для первого запуска,
быстрее в работе и безопаснее при изменении настроек Windows.

-   🔑 **Простое подключение ИИ:** Ключ Gemini теперь вводится прямо в
    программе, хранится на компьютере в защищённом виде и при необходимости
    меняется с главного экрана.
-   📴 **Полноценная работа без ИИ:** Программу можно запустить без ключа.
    Она выполнит очистку и применит осторожные рекомендации из встроенной базы.
    Если ИИ временно недоступен, работа автоматически продолжится без него.
-   🛡️ **Усиленная защита Windows:** Жизненно важные службы, системные папки,
    корни дисков и личная папка пользователя защищены от опасных изменений.
-   🧹 **Безопасная очистка:** ИИ больше не выбирает отдельные файлы для
    удаления. Программа сама составляет проверенный список и пропускает всё,
    что может быть важным для системы.
-   ⚡ **Работа стала быстрее:** Поиск мусора ускорился примерно в 15 раз,
    сбор сведений о компьютере больше не подвешивает окно, а фоновая анимация
    стала примерно втрое легче.
-   🖥️ **Исправлены основные ошибки:** Программа снова правильно определяет
    оборудование, проверяет корзину и остатки установки драйверов, корректно
    отменяет оптимизацию и больше не продолжает работу после закрытия окна.
-   ✨ **Обновлён интерфейс:** Окно подключения ИИ стало компактнее, на
    главном экране отображается текущий режим, а значки и оформление приведены
    к единому стилю.
-   📦 **Один файл для запуска:** Готовая версия распространяется одним EXE
    без дополнительных папок. Всё необходимое временно распаковывается
    автоматически и удаляется после закрытия программы.
-   ✅ **Больше стабильности:** Ошибка на одном этапе больше не останавливает
    остальные безопасные действия, а исправленные сценарии регулярно
    проверяются перед выпуском обновлений.

*Версия 1.0.4 делает WinSpector Pro удобнее для обычного пользователя,
сохраняя главное — скорость, понятность и безопасность.*

## 🛠️ Установка и запуск

1.  Перейдите на страницу **[Релизы](https://github.com/deeCaTofficial/WinSpectorPro/releases/latest)**.
2.  Скачайте архив `WinSpectorPro-vX.X.X.zip` из раздела "Assets".
3.  Распакуйте архив в удобное место.
4.  Запустите `WinSpectorPro.exe`. При необходимости предоставьте права администратора.

### Подключение ИИ

При первом запуске программа предложит указать ключ Google Gemini. Ключ
**бесплатный** — его выдают за минуту в [Google AI Studio](https://aistudio.google.com/app/apikey).
Он хранится только на вашем компьютере в зашифрованном виде (Windows DPAPI)
и никуда больше не передаётся.

Ключ можно не указывать: тогда приложение работает **без ИИ** — чистит систему
и применяет безопасные настройки из встроенной базы знаний, но без
персонального подхода. Подключить ИИ можно в любой момент с главного экрана.

*Более подробную информацию можно найти в [Руководстве пользователя](./docs/USER_GUIDE.md).*

## 🔧 Технический обзор

WinSpector Pro построен на **Python 3.10+**, **PyQt6** и **`asyncio`** (через `qasync`). Решения принимает **Google Gemini** (SDK `google-genai`), но его ответ считается недоверенным: план проходит через независимые барьеры безопасности, а пути к удаляемым файлам ИИ не контролирует вовсе.

```bash
# Запуск из исходников
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
copy .env.example .env    # укажите GEMINI_API_KEY
.venv\Scripts\python src/main.py

# Тесты и линтер
.venv\Scripts\pytest tests/ --cov
.venv\Scripts\ruff check src/ scripts/ tests/
```

Подробнее об устройстве проекта читайте в документе **[Архитектура проекта](./docs/ARCHITECTURE.md)**.
